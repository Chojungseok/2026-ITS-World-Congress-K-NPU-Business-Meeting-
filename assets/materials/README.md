# 발표자료 저장 폴더

현재 실제 발표자료 PDF는 없습니다. 임시 PDF나 기존 브로셔 사본을 넣지 않습니다.

공개 승인을 확인한 실제 PDF를 확보한 뒤 ITS 자료는 `its/<company-id>/`, NPU 자료는 `npu/<company-id>/` 하위에 넣는 방식을 권장합니다. 파일명은 실제 자료를 받았을 때 정하세요. 기업 소개 브로셔는 기존 `assets/brochures/` 파일을 계속 사용합니다.

등록 원본은 `assets/js/material-catalog.js` 하나입니다. 자세한 절차는 `docs/material-library-v4.md`를 참고하세요.
